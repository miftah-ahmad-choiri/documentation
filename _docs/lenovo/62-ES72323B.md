## **Course overview**

Course ES72323B provides technical information for service personnel who are required to service and maintain the ThinkSystem SD650 V3 (MT 7D1M), SD650-I V3 (MT 7D7L), SD650-N V3 (7D7N), and DW612S enclosure (MT 7D1L).

The intent of this course is to provide an overview of key storage array components and features, update procedures, and problem determination techniques.

By watching the videos, you will learn how to install and remove system components.


This update includes information about the new SD650-N V3 node tray and replacement procedures for putty pads and the Intel GPU OAM and GPU carrier base board (CBB).

**Objective:** 
- Describe the features and specifications of the ThinkSystem SD650 V3 server, SD650-I V3 GPU, SD650-N V3 node tray, and DW612S enclosure
- Identify the ThinkSystem SD650 V3 server, SD650-I V3 GPU node tray, and DW612S enclosure unit and components
- Describe the SMM2 features and functions
- Describe the specific problem determination steps and explain how to troubleshoot issues with the Intel GPU and DW612S enclosure

**Topics**  
- Topic 1 – Product overview 
- Topic 2 – Features specification 
- Topic 3 – SMM2 overview 
- Topic 4 – Problem determination and troubleshooting  
- Topic 5 – Hardware replacement tips 
- Topic 6 – Summary
