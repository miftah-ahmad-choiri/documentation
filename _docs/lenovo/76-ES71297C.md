## **Course overview**

Course ES71297C provides technical information for service personnel who are required to service and maintain the System x3550 M5 and x3650 M5 machine type 8869 and 8871.
The course provides an overview of the system and the architecture information of the system. By viewing the videos, students will learn how to install and remove the system components.
In this update, students will also learn the differences between the x3650 M5 generic machine type 8871 and machine type 8871-AC3.

**Course objectives**
- Describe the features of the System x3550 M5 and x3650 M5 machine type 5463, 5462, 8869 and 8871.
- Describe the System x3550 M5 and x3650 M5 machine type 8869 and 8871 mechanical design.
- Describe the different subsystems.
- Describe the problem determination steps and explain how to troubleshoot the System x3550 M5 and x3650 M5 machine type 5463, 5462, 8869 and 8871.

**Topics**  
- Topic 1 – Introducing the Lenovo System x3550 M5 and x3650 M5 machine type 5463, 5462, 8869, and 8871 
- Topic 2 – Features and specifications 
- Topic 3 – System diagrams 
- Topic 4 – Problem determination and troubleshooting 
- Topic 5 – End of course summary
