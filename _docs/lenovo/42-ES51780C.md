## **Course overview**

Course ES51780C provides technical information for service personnel who are required to service and maintain Lenovo ThinkSystem storage controllers.

The course provides an overview of ThinkSystem storage controller features, specifications, and management tools.

This course update includes several new storage controller options and information about Intel VROC software RAID.
Course objectives

**Students will be able to:**
* Describe the features of the ThinkSystem storage adapters
* Describe the features of the NVMe and M.2 storage device
* Describe the features of the Intel VROC software RAID
* Describe the features of the LSI Storage Authority software
* Identify the differences between RAID adapters
* Describe how to configure RAID adapters with the different tools
* Describe how to configure CacheCade SSD caching in HII

**Prerequisites** <br>
Although there are no specific prerequisites for this course, you should have some knowledge of high performance computing (HPC) systems, be familiar with the general administration of a network cluster, and have problem determination and troubleshooting skills. 

**Topics** 
* Topic 1 – Product overview 
* Topic 2 – Features and specifications 
* Topic 3 – XClarity Controller and ThinkSystem storage subsystem 
* Topic 4 – LSI Storage Authority 
* Topic 5 – RAID setup in different tools 
* Topic 6 – End-of-course summary
