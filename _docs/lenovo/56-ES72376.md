## **Course overview**

Course ES72376 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR645 V3 machine types 7D9C and 7D9D. 

The intent of this course is to provide an overview of the SR645 V3 specifications, components, system configuration, and management tools. 

By watching the videos, you will learn how to install and remove system components.

**Objective:** 
- Describe the Lenovo ThinkSystem SR645 V3 server and components
- List the SR645 V3 server specifications
- Describe the SR645 V3 server configurations and block diagrams
- Describe the SR645 V3 server management tools
- Describe the problem determination steps and explain how to troubleshoot issues with the SR645 V3


**Topics**  
- Topic 1 – Introducing the ThinkSystem SR645 V3 server 
- Topic 2 – SR645 V3 specifications 
- Topic 3 – SR645 V3 server configurations and diagrams 
- Topic 4 – Parts replacement tips 
- Topic 5 – Problem determination and troubleshooting 
- Topic 6 – End-of-course summary
