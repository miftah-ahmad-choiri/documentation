## **Course overview**

Course ES40610D is an update to ES40610C. This course provides technical information for service personnel who are required to service and maintain the Lenovo System x servers. Updates include the new FoD key management system (KMS) Web site, FoD handling scope by SSRs and FoD key installation after hardware replacement.
This course provides an overview of the Features on Demand (FoD) Technology, describes how to obtain a license, explains how to install an activation key, and how to verify the license of the keys. This course also explains how to maintain the FoD activation keys on both System x and Software Group Appliance products.

**Course objectives**

- Provide an overview of the Features on Demand technology.
- Explain how the key management works.
- Explain how the activation management utility works.
- Describe the activities that are required by the remote technical support agents.

**Topics**  
- Topic 1 – Introducing the Features on Demand technology 
- Topic 2 – FoD key management system 
- Topic 3 – FoD activation key management through Advanced Setup Utility 
- Topic 4 – FoD activation key management through DSA 
- Topic 5 – Features on Demand support plan 
- Topic 6 – Features on Demand servicer activities 
- Topic 7 – FoD key installation after hardware replacement 
- Topic 8 – End of course summary
