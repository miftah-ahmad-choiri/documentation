## **Course overview**

Course ES71741 provides technical information for service personnel who are required to service and maintain the Lenovo ThinkSystem SN550 server (machine type 7X16). <br>
The intent of this course is to provide an overview of the Lenovo ThinkSystem SN550 server (machine type 7X16) features and specifications and server configurations and diagrams.

**Course objectives**

* Describe the Lenovo ThinkSystem SN550 server and components.
* List the Lenovo ThinkSystem SN550 server features and specifications.
* List the Lenovo ThinkSystem SN550 server configurations and diagrams.


**Prerequisites** <br>
In addition to taking the prerequisite courses listed below for ES71741, you must also have some knowledge of high-volume network transaction processing systems, be familiar with the general administration of a high-volume, multicore server, and have problem determination and troubleshooting skills. 
* [ES41758](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41758) - ThinkSystem servers architecture introduction  
* [ES51757](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757) - Introducing ThinkSystem tools  
* [ES41759](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759) - ThinkSystem problem determination  
* [ES51780](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780) - Servicing the ThinkSystem storage controllers  

**Topics**
* Topic 1 – Introducing the Lenovo ThinkSystem SN550 server and components. 
* Topic 2 – Lenovo ThinkSystem SN550 server features and specifications. 
* Topic 3 – Lenovo ThinkSystem SN550 server configurations and diagrams. 
* Topic 4 – End of course summary
