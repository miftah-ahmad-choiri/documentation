## **Course overview**

Course ES21492 teaches service personnel how to setup and configure the eXFlash DIMM in a VMWare and Linux environment.
By viewing these videos, you will be able to describe the process of installing an eXFlash DIMM and performing device driver and firmware updates in a VMWare and Linux environment.
