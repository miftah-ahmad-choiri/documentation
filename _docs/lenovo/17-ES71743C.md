Machine type(s): 7X05 7X06 <br>
Course duration: 90 minutes <br>

## **Course overview** 
Course ES71743C provides technical information for service personnel who are required to service and maintain the Lenovo ThinkSystem SR650 server MT 7X05 and MT 7X06. <br>
The intent of this course is to provide an overview of the Lenovo ThinkSystem SR650 MT 7X05 and MT 7X06 server specifications, components, and system configuration.

The update to this course includes an overview of rich NVMe configurations and cable routing diagrams. By watching the videos, students will learn how to install and remove the system components. By studying the simulators, students will learn how to update the system configuration.

**Course objectives** <br>
Students will be able to:
* Describe the Lenovo ThinkSystem SR650 server MT 7X05 and MT 7X06 and components.
* List the server specifications.
* Describe the new Intel 6137 CPU and the system configuration changes to the ThinkSystem SR650.
* Describe the rich NVMe configuration.
* Describe the server configurations and diagrams.

**Prerequisites** <br> 
Before you begin, take the following prerequisites for this course. You must also have knowledge of high-performance computing (HPC) systems, be familiar with the general administration of a high-volume, multi-core server, and have problem determination and troubleshooting skills. 
* [ES41758](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41758) - ThinkSystem servers architecture introduction  
* [ES51757](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757) - Introducing ThinkSystem tools 
* [ES41759](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759) - ThinkSystem problem determination  
* [ES51780B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780B) - Servicing the ThinkSystem storage controller  

**Topics** 
* Topic 1 – Introducing the Lenovo ThinkSystem SR650 server and components 
* Topic 2 – Lenovo ThinkSystem SR650 rich NVMe configuration 
* Topic 3 – Lenovo ThinkSystem SR650 server specifications 
* Topic 4 – Intel 6137 CPU and the system configuration changes to the ThinkSystem SR650 server 
* Topic 5 – Server configurations and diagrams 
* Topic 6 – End of course summary
