## **Course overview**
Course ES72326 provides technical information for service personnel who are required to service and maintain the ThinkSystem ST50 V2, machine types 7D8J and 7D8K.

The intent of this course is to provide an overview of the ST50 V2 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
- Describe the ThinkSystem ST50 V2 server
- Describe the server features and specifications
- Identify the server diagram
- Describe the problem determination and VPD update procedures for the ST50 V2


**Topics** 
- Topic 1 – Introducing the ThinkSystem ST50 V2 server 
- Topic 2 – ST50 V2 system configurations and diagrams 
- Topic 3 – Problem determination and troubleshooting 
- Topic 4 – End-of-course summary
