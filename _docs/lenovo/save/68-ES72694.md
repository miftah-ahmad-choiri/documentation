## **Course overview**

Course ES72694 provides technical information for service personnel who are required to service and maintain the ThinkSystem N1380 Neptune DWC enclosure (MT 7DDH) and the SC750 V4 Neptune server node (MT 7DDJ).

The intent of this course is to provide an overview of key components, features, field service tips, and problem determination techniques.

By watching the videos, you will learn how to install and remove system components.

**Course Objectives**

- Describe the features and specifications of the ThinkSystem N1380 Neptune DWC enclosure and the SC750 V4 Neptune server
- Identify the components of the ThinkSystem N1380 Neptune DWC enclosure and the SC750 V4 Neptune server
- Describe the features and functions of SMM3
- Describe the specific problem determination steps and explain how to troubleshoot issues with the ThinkSystem N1380 Neptune DWC enclosure and the SC750 V4 Neptune server

**Topics**  
- Topic 1 – Product overview 
- Topic 2 – Features specification 
- Topic 3 – SMM2 overview 
- Topic 4 – Problem determination and troubleshooting  
- Topic 5 – Hardware replacement tips 
- Topic 6 – Summary
