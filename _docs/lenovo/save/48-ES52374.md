## **Course overview**

Course ES52374 provides an overview of the software tools supported by ThinkSystem servers and the functions they can be used for. 

The intent of this course is to enable service personnel who are required to service and maintain ThinkSystem servers to understand how to use available software tools to perform common servicing tasks.

**Course Objectives**
- Describe the new features of the software tools supported by ThinkSystem V3 servers
- Describe the Firmware and Root of Trust Security Module and explain how to service it
- Describe the features introduced in the newer versions of existing software tools that support ThinkSystem servers

**Topics**  
- Topic 1 – Tools for the ThinkSystem V3 server platform – overview 
- Topic 2 Firmware and Root of Trust security module  
- Topic 3 – Lenovo XClarity Controller 2 on ThinkSystem V3 servers 
- Topic 4 – Lenovo XClarity Provisioning Manager 4 on ThinkSystem V3 servers 
- Topic 5 – Lenovo XClarity Essentials on ThinkSystem V3 servers  
- Topic 6 – UEFI on ThinkSystem V3 servers  
- Topic 7 – LXCA 4.0 on ThinkSystem V3 servers
