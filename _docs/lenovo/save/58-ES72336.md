## **Course overview**

Course ES72336 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR650 V3, machine types 7D75 and 7D76.

The intent of this course is to provide an overview of the SR650 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
- Describe the features and specifications of the ThinkSystem SR650 V3 server
- Identify the components of the ThinkSystem SR650 V3 server
- Describe the configurations of SR650 V3 server
- Describe the SR650 V3 server management tools
- Describe the specific problem determination steps and explain how to troubleshoot issues with the ThinkSystem SR650 V3 server

**Topics**  
- Topic 1 – Product overview 
- Topic 2 – System configuration and diagrams 
- Topic 3 – Problem determination and troubleshooting 
- Topic 4 – End-of-course summary
