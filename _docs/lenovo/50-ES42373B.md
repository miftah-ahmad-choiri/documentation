## **Course overview**

Course ES42373B provides technical information for service personnel who are required to service and maintain ThinkSystem V3 servers.

This course includes information about ThinkSystem V3 servers, including an architecture overview based on the Intel Eagle Stream Sapphire Rapids-SP processors.

This course update introduces Intel On Demand features and explains how to check a processor’s PPIN and how to apply a license key.



**Course objectives**
- Identify the differences between the 3rd Generation and Next Generation Intel Xeon Scalable processors
- Describe the features of the Next Generation Intel Xeon Scalable processor in ThinkSystem V3 servers
- Describe the Intel Xeon Scalable processor naming rules
- Describe the supported memory and storage features on ThinkSystem servers
- Describe the Intel On Demand features of Intel V3 processors


**Topics**  
- Topic 1 – What’s new 
- Topic 2 – ThinkSystem V3 architecture overview  
- Topic 3 – Intel Eagle Stream platform product overview 
- Topic 4 – Next Generation Intel Xeon Scalable processor features and configurations 
- Topic 5 – Intel On Demond feature 
- Topic 6 – End-of-course summary
