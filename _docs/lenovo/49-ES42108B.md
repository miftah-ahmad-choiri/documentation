## **Course overview**

Course ES42108B provides technical information for service personnel who are required to service and maintain the ThinkSystem V2.

This course update includes information about the new two-socket ThinkSystem V2, including an architecture overview based on the Intel Whitley Ice Lake-SP processors.

**Course objectives**

- Describe the features and technology of the Intel Xeon Scalable processor Gen 3
- Identify the differences between the Intel Xeon Scalable processor Gen 1, Gen 2, and Gen 3
- Describe the different processor heatsink modules (PHM) used in the ThinkSystem V2 servers
- Describe the Intel Xeon Scalable processor naming rules
- Identify ThinkSystem servers supported memory and storage features


**Topics**  
- Topic 1 – New: ThinkSystem V2 two-socket product overview 
- Topic 2 – Product overview 
- Topic 3 – Intel Xeon Scalable processor Gen 3 features and configurations 
- Topic 4 – Processor heatsink module 
- Topic 5 – End-of-course summary
