## **Course overview**

Course ES42430 provides architecture information for service personnel who are required to service and maintain ThinkSystem V3 servers with AMD EPYC processors.

**Course Objectives**
- Describe the key components and technology of the EPYC platforms
- Describe the ThinkSystem support for AMD processor levels and features
- Describe memory support and configuration rules
- Describe AMD processor heat sink and hardware features

**Topics** 
- Topic 1 – EPYC processor overview 
- Topic 2 – EPYC processor features and configurations  
- Topic 3 – Supported memory introduction and configuration 
- Topic 4 – Processor with heat sink assembly introduction 
- Topic 5 – End-of-course summary
