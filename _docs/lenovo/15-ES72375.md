Course code: [ES72375](https://lenovoedu.lenovo.com/course/view.php?id=1002) <br>
Machine type(s): 7D9G,7D9H <br>
Course duration: 120 minutes <br>

## **Course overview**
Course ES72375 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR635 V3 machine types 7D9G and 7D9H.

**Course Objectives** <br>
Students will be able to:
* Describe the ThinkSystem SR635 V3 server and components
* List the SR635 V3 server specifications
* Describe the SR635 V3 server configurations and block diagrams
* Describe the SR635 V3 server management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR635 V3

**Prerequisites**  
* [ES42430](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42430) – AMD EPYC processor architecture for ThinkSystem V3 servers 
* [ES51757C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757C) – Introducing ThinkSystem tools  
* [ES52374](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES52374) – ThinkSystem tools for the ThinkSystem V3 platform  
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination 
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing Lenovo ThinkSystem storage controllers 
* [ES40610D](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES40610D) – Introducing the Features on Demand technology 
* [ES42190](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42190) - Servicing the ThinkSystem 4350/5350/9350 RAID/HBA series adapters 

**Topics**  
* Topic 1 – Product overview 
* Topic 2 – System configuration and diagrams 
* Topic 3 – Problem determination and troubleshooting 
* Topic 4 – Hardware replacement tips 
* Topic 5 – End-of-course summary
