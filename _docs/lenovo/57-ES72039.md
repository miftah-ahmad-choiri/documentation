## **Course overview**

Course ES72039 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR650 V2 machine types 7Z72, 7Z73, and 7D3Z.

The intent of this course is to provide an overview of the SR650 V2 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**

- Describe the Lenovo ThinkSystem SR650 V2 server and components
- List the SR650 V2 server specifications
- Describe the SR650 V2 server configurations and diagrams
- Describe the SR650 V2 server management tools
- Describe the problem determination steps and explain how to troubleshoot issues with the SR650 V2

**Topics** 
- Topic 1 – Introducing the ThinkSystem SR650 V2 server 
- Topic 2 – SR650 V2 specifications 
- Topic 3 – SR650 V2 server configurations and diagrams 
- Topic 4 – Management tools 
- Topic 5 – Problem determination and troubleshooting 
- Topic 6 – End-of-course summary
