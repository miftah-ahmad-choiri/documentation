Machine type(s): 7D72, 7D73 <br>
Course duration: 120 minutes


## **Course overview**

Course ES72337 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR630 V3, machine types 7D72 and 7D73.

The intent of this course is to provide an overview of the SR630 V3 specifications, components, system configuration, management tools, and problem determination techniques.

**Course objectives**
- Describe the features and specifications of the ThinkSystem SR630 V3
- Identify the components of the SR630 V3
- Describe the configurations of SR630 V3
- Describe the SR630 V3 server management tools
- Describe the specific problem determination steps and explain how to troubleshoot issues with the SR630 V3


**Topics** 
- Topic 1 – Product overview 
- Topic 2 – System configurations and diagrams  
- Topic 3 – Problem determination and troubleshooting 
- Topic 4 – End-of-course summary
