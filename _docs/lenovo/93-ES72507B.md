## **Course overview**

Course ES72507B provides technical information for service personnel who are required to service and maintain the ThinkEdge SE350 V2 edge server (machine types: 7DA9, 7DBK) and the ThinkEdge SE360 V2 edge server (machine type: 7DAM).

This course update introduces wave 2 updates, including the AC power input, additional SE360 V2 network configurations, new SE360 V2 riser configurations, new mounting options, and the implementation of ThinkEdge security 2.0.

The intent of this course is to provide an overview of the SE350 V2 and SE360 V2 specifications, components, system configurations, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
- Describe the ThinkEdge SE350 V2 and ThinkEdge SE360 V2 and their components
- Describe the features and specifications of the SE350 V2 and SE360 V2 
- Describe the different SE350 V2 and SE360 V2 mounting options and explain how to install them
- Describe the SE350 V2 and SE360 V2 security mechanism and explain how to activate the servers
- Describe the problem determination steps and explain how to troubleshoot issues with the SE350 V2 and SE360 V2

**Topics**  
- Topic 1 – ThinkEdge SE350 V2 and SE360 V2 product overview 
- Topic 2 – ThinkEdge SE350 V2 and SE360 V2 features and specifications 
- Topic 3 – System configuration and diagrams 
- Topic 4 – Mounting options 
- Topic 5 – Security mechanism and system activation 
- Topic 6 – Problem determination and troubleshooting 
- Topic 7 – End-of-course summary
