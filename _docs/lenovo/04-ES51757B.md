## **Course overview**

Course ES51757B provides an overview of all the software tools that are supported by ThinkSystem servers, and what functions they are used for.

The intent of this course is to enable service personnel, who are required to service and maintain ThinkSystem servers, to understand how to use available software tools to perform common servicing tasks.

This update includes the new features of ThinkSystem tools for ThinkSystem V2 servers.

**Course objectives**

Students will be able to:
* List the software tools supported by ThinkSystem servers.
* Describe the key functions that each software tool is capable of performing.
* Describe the steps to perform common tasks, such as firmware updates, logging into software interfaces, saving service data logs with the software tools that are available.
* Describe the features introduced in the newer versions of existing software tools that support ThinkSystem servers.
