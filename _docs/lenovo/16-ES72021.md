Course code: [**ES72021**](https://lenovoedu.lenovo.com/course/view.php?id=752) <br>
Machine type(s): 7D2Y 7D2X <br>
Course duration: 120 minutes <br>

## **Course overview** <br>
Course ES72021 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR645 machine types 7D2Y and 7D2X.

The intent of this course is to provide an overview of the SR645 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives** <br>
Students will be able to:
* Describe the Lenovo ThinkSystem SR645 server and components
* List the SR645 server specifications
* Describe the SR645 server configurations and diagrams
* Describe the SR645 server management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR645
