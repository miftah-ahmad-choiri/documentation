## **Course overview**

Course ES71791 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR590 server (machine type 7X98 and 7X99).
The intent of this course is to provide an overview of the Lenovo ThinkSystem SR590 server specifications, components, and system configuration. By viewing the videos, students will learn how to install and remove the system components.

**Course objectives** <br>
Students should be able to:
* Describe the Lenovo ThinkSystem SR590 server and components.
* List the Lenovo ThinkSystem SR590 server specifications.
* Describe the Lenovo ThinkSystem SR590 server configurations and diagrams.
* Describe the Lenovo ThinkSystem SR590 server parts replacement procedures.
* Describe the problem determination steps and explain how to troubleshoot the ThinkSystem SR590.
