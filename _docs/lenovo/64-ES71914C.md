## **Course overview**

Course ES71914C provides technical information for service personnel who are required to service and maintain Lenovo ThinkSystem DM Series storage systems.

The intent of this course is to familiarize service personnel with the product components, features and specifications, management tools, command-line operations, and problem determination procedures for the system.

By watching the videos, you will learn how to install and remove system components.

This course update includes an introduction to the new IOM and DM600S expansion enclosure drive drawer, and also information on how to identify failed components prior to replacement.

**Course objectives**

- Describe ThinkSystem DM Series storage systems and their components
- List the features and specifications
- Describe how to cable DM Series storage systems
- Explain the power on and power off procedures
- Explain how to connect the console and use command lines
- Describe how to replace FRUs
- Describe how to update firmware using the CLI and ThinkSystem Storage Manager
- Describe the problem determination steps and explain how to troubleshoot issues with ThinkSystem DM Series storage systems
