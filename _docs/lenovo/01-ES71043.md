## **Course overview**

Course ES71043 teaches service personnel the skills that are required to define, navigate, and configure the **Lenovo XClarity Administrator**.

**The intent of this course is to:**
* Provide an overview of Lenovo XClarity Administrator and the supported systems.s
* Define the support strategy.
* Define and describe the administration objectives.
* Define and describe the administration tasks.
* Define resource discovery, security, monitoring, REST interface, and Windows® Powershell.
  
**Course Objectives Students will be able to**:
1. Define the support structure. 
2. Describe the virtual appliance.
3. Describe the discovery and inventory process. 
4. Describe the monitoring and events capabilities 
5. Navigate the GUI interface.
6. Understand and navigate the Windows Powershell. 
7. Describe the firmware update process.
8. Describe the configuration patterns. 
9. Describe the OS deployment procedure.
