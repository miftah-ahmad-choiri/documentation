## **Course overview**

Course ES71911C provides technical information for service personnel who are required to service and maintain the Lenovo ThinkSystem SE350 edge server machine type 7D1X, 7Z46, 7D27, and 7D1R (ThinkSystem E1 and E2 Enclosures). This course update includes information about new service actions required before replacing a system board, Mobile application (iOS version) issues and workarounds, and the new, no-activation-needed SE350 Standard model.

The intent of this course is to provide an overview of the SE350 specifications, components, system configuration, and activation. By watching the videos, you will learn how to install and remove system components.

**Course objectives**

- Describe how to create a ThinkShield service support account
- Describe the Lenovo ThinkSystem SE350 edge server and its components
- Describe the features and specifications of the Lenovo ThinkSystem SE350 edge server
- Describe the different ThinkSystem SE350 edge server mounting options and how to install them
- Describe the ThinkSystem SE350 edge server security mechanism and how to activate the server
- Describe the problem determination steps and explain how to troubleshoot issues with the Lenovo ThinkSystem SE350 edge server
