Machine type(s): 7DC4,7DC5,7DC6 <br>
Course duration: 90 minutes <br>


## **Course overview**

Course ES72516 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR950 V3, machine types 7DC4, 7DC5 and 7DC6.<br>
The intent of this course is to provide an overview of the SR950 V3 specifications, components, system configurations, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives** <br>
Students will be able to:
* Describe the features and specifications of the ThinkSystem SR950 V3
* Identify the components of the SR950 V3
* Describe the configurations of the SR950 V3
* Describe the SR950 V3 management tools
* Describe the specific problem determination steps and explain how to troubleshoot issues with the SR950 V3
