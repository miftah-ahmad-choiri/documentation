## **Course overview**

Course ES41999 provides architecture information for service personnel who are required to service and maintain ThinkSystem servers with AMD EPYC processors.

**Course objectives**
- Describe the key components and technology of the AMD EPYC platforms
- Describe Lenovo ThinkSystem support for AMD processor levels and features
- Describe memory support and configuration rules
- Describe AMD processor heat sink and hardware features

**Topics** 
- Topic 1 – AMD EPYC processor overview 
- Topic 2 – AMD EPYC processor features and configurations  
- Topic 3 – Supported memory introduction and configuration 
- Topic 4 – Processor with heat sink assembly introduction 
- Topic 5 – End-of-course summary 

Click on [Lenovo_ThinkSystem](https://lenovoedu.lenovo.com/mod/url/view.php?id=10662) (Intel base) to open the resource.
