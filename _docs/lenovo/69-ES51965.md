## **Course overview**

Course ES51965 provides technical information for service personnel who are required to service and maintain the Lenovo ThinkSystem servers with the Intel Optane DC Persistent Memory Module (DCPMM).
The intent of this course is to familiarize level 1 service personnel with DCPMM features and specifications. The course also includes DCPMM configuration, replacement, and problem determination procedures.

**Course objectives**
- Describe the DCPMM features
- Describe the DCPMM operation modes
- Describe the DCPMM population rules
- Describe the DCPMM configuration procedures
- Describe the method used to update DCPMM firmware
- Describe the method used to replace the DCPMM on the system
- Describe the problem determination and troubleshooting steps on the DCPMM
