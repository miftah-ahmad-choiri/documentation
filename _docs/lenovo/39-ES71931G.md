## **Course overview**

Course ES71931G provides technical information for service personnel who are required to service and maintain the ThinkSystem DE Series storage arrays (MT 7Y70,7Y71,7Y74,7Y75,7Y76,7Y77,7Y78,7Y79,7Y80,7Y63,7Y68,7Y69, 7DB7CTO1WW, 7DB7CTO2WW,7DB6CTO1WW, and 7DB6CTO2WW).

The intent of this course is to provide an overview of key storage array components and features, update procedures, and problem determination techniques. By watching the videos, you will learn how to install and remove the storage array components.

This update includes information about the new DE6400 and DE6600 series storage arrays.

**Course Objectives**

* Describe the features and specifications of the ThinkSystem DE Series storage arrays
* Describe the DE Series plugin for vCenter feature
* Describe the DE Series storage arrays configuration
* Describe the management software of the storage arrays
* Describe the process for changing host port protocols
* Describe the process used to enable the premium feature key
* Describe the problem determination steps and explain how to troubleshoot issues with the storage arrays
* Describe the hardware replacement tips
