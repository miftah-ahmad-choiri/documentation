Machine type(s): 7D9E 7D9F <br>
Course duration: 120 minutes <br>

## **Course overview**
Course ES72377 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR655 V3, machine types 7D9E and 7D9F. <br>
The intent of this course is to provide an overview of the SR655 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components. <br>
This update includes information about the supported slots at the front of the server.

**Course objectives** <br>
Students will be able to:
* Describe the ThinkSystem SR655 V3 server and components
* List the SR655 V3 server specifications
* Describe the SR655 V3 server configurations and diagrams
* Describe the SR655 V3 server management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR655 V3

**Prerequisites**  
* [ES42430](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42430) – AMD EPYC processor architecture for ThinkSystem V3 servers  
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing the ThinkSystem storage controllers 
* [ES51757B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757B) – Introducing ThinkSystem tools 
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination 
* [ES52374](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES52374) – ThinkSystem tools for the ThinkSystem V3 platform  
* [ES42190](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42190) – Servicing the ThinkSystem 4350/5350/9350 RAID/HBA series adapters  

**Topics**

* Topic 2 – SR655 V3 specifications
