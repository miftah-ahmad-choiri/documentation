## **Course overview**

Course ES72482 provides technical information for service personnel who are required to service and maintain the ThinkSystem HS350X V3 (machine types: 7DE3, 7DBM).

The intent of this course is to provide an overview of system components, management features, system update procedures, and problem determination techniques.

By watching the videos, you will learn how to install and remove system components.

**Course Objectives**

* Describe the features and specifications of the ThinkSystem HS350X V3
* Identify the components of the HS350X V3
* Describe the configurations of the HS350X V3 
* Describe the HS350X V3 management features
* Describe the specific problem determination steps and explain how to troubleshoot issues with the HS350X V3

**Prerequisites**  <br>
Although there are no specific prerequisites for this course, you should have some knowledge of high performance computing (HPC) systems, be familiar with the general administration of a network cluster, and have problem determination and troubleshooting skills. 

**Topics** 
* Topic 1 – Product overview 
* Topic 2 – System configurations and diagrams 
* Topic 3 – Management tools overview 
* Topic 4 – BMC web GUI 
* Topic 5 – PMU CLI tool 
* Topic 6 – Problem determination and troubleshooting  
* Topic 7 – Hardware replacement tips 
* Topic 8 – Summary
