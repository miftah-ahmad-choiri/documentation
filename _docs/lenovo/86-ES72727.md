## **Course overview**

Course ES72727 provides technical information for service personnel who are required to service and maintain the ThinkEdge SE100 (machine types: 7DGR, 7DGV)
The intent of this course is to provide an overview of the SE100 specifications, components, system configuration, management tools, and problem determination techniques. By watching the videos, you will learn how to install and remove system components.

**Course objectives**

- Describe the ThinkEdge SE100 server and components
- List the SE100 features and specifications
- Describe the SE100 configurations and block diagrams
- Describe the SE100 management tools
- Describe the problem determination steps and explain how to troubleshoot issues with the SE100

**Topics**  
- Topic 1 – ThinkEdge SE100 product overview 
- Topic 2 – ThinkEdge SE100 features and specifications  
- Topic 3 – System configurations and block diagrams 
- Topic 4 – Mounting options  
- Topic 5 – Security overview and system activation   
- Topic 6 – Problem determination and troubleshooting 
- Topic 7 – End-of-course summary
