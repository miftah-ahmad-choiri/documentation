Course duration: 120 minutes 

## **Course overview**

Course ES72436 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR850 V3, machine types 7D96, 7D97, and 7D98. <br>
The intent of this course is to provide an overview of the SR850 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course Objectives** <br>
* Describe the Lenovo ThinkSystem SR850 V3 server and components
* List the SR850 V3 specifications
* Describe the SR850 V3 configurations and block diagrams
* Describe the SR850 V3 management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR850 V3

**Prerequisites**  
* [ES42373](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42373) – Intel Xeon processor architecture for ThinkSystem V3 servers  
* [ES51757C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757B) – Introducing ThinkSystem tools 
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination  
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing Lenovo ThinkSystem storage controllers  
* [ES40610D](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES40610D) – Introducing the Features on Demand technology  

**Topics**  
* Topic 1 – Product overview 
* Topic 2 – SR850 V3 specifications
