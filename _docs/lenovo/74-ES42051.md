## **Course overview**

Course ES42051 provides technical information for service personnel who want to become familiar with Nutanix and its hypervisor. This course provides an introduction to the Nutanix core architecture and its hypervisor. Students will also learn some troubleshooting tools to determine system health and gather logs.

**Course objectives**
- Describe Nutanix Core
- Describe the Prism architecture and nCLI
- Describe the NCC installation and upgrade procedures
- Describe the AHV, ESXi, and Hyper-V architecture
- Describe the useful tools and troubleshooting actions used to work with Nutanix


**Topics**  
- Topic 1 – Nutanix Core introduction 
- Topic 2 – Prism introduction 
- Topic 3 – Nutanix Command-Line Interface (nCLI) introduction 
- Topic 4 – AHV architecture 
- Topic 5 – ESXi architecture 
- Topic 6 – Hyper-V architecture 
- Topic 7 – Troubleshooting tools
