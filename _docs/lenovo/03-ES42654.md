## **Course overview**

Course ES42654 provides an overview of the Lenovo XClarity One software tool, which is supported by ThinkSystem servers. It also introduces the functions it is used for.

The intent of this course is to provide technical information to service personnel who are required to service and maintain ThinkSystem servers and use Lenovo XClarity One to perform common servicing tasks.

**Course Objectives** <br>
Students will be able to:
* Describe the features of Lenovo XClarity One
* Describe the user roles and organization of Lenovo XClarity One
* Describe the Lenovo XClarity One login procedure
* Explain management hubs and how to connect them to Lenovo XClarity One
* Outline the steps used to add a device to Lenovo XClarity One
* Explain how to perform common tasks such as monitoring devices, submitting a Call Home request, and uploading service data logs

**Prerequisites**  
* **ES51757B** – Introducing ThinkSystem tools 
* **ES52374** – ThinkSystem tools for the ThinkSystem V3 platform
