## **Course overview**

Course ES72338 provides technical information for service personnel who are required to service and maintain the ThinkSystem ST650 V3, machine types 7D7A, 7D7B, and 7D7C.

The intent of this course is to provide an overview of the ST650 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
* Describe the features and specifications of the ThinkSystem ST650 V3
* Identify the components of the ST650 V3
* Describe the configurations of the ST650 V3
* Describe the ST650 V3 management tools
* Describe the specific problem determination steps and explain how to troubleshoot issues with the ST650 V3

**Prerequisites**  
* [ES42373](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42373) – Intel Xeon processor architecture for ThinkSystem V3 servers  
* [ES51757B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757B) – Introducing ThinkSystem tools  
* [ES52374](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES52374) – ThinkSystem tools for the ThinkSystem V3 platform  
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination  
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing Lenovo ThinkSystem storage controllers 
* [ES42190](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42190) - Servicing the ThinkSystem 4350/5350/9350 RAID/HBA series adapters  

**Topics** 
* Topic 1 – Product overview 
* Topic 2 – System configuration and diagrams 
* Topic 3 – Problem determination and troubleshooting 
* Topic 4 – End-of-course summary
