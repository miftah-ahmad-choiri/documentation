Course duration: 120 minutes


## **Course overview**

Course ES72378 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR665 V3, machine types 7D9A and 7D9B.

The intent of this course is to provide an overview of the SR665 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
- Describe the ThinkSystem SR665 V3 server and components
- List the SR665 V3 server specifications
- Describe the SR665 V3 server configurations and diagrams
- Describe the SR665 V3 server management tools
- Describe the problem determination steps and explain how to troubleshoot issues with the SR665 V3

**Topics**  
- Topic 1 – Introducing the ThinkSystem SR665 V3 server 
- Topic 2 – SR665 V3 specifications 
- Topic 3 – SR665 V3 server configurations and diagrams 
- Topic 4 – Management tools 
- Topic 5 – Problem determination and troubleshooting 
- Topic 6 – End-of-course summary
