Course code: [ES72367](https://lenovoedu.lenovo.com/course/view.php?id=1020) <br>
Machine type(s): 7D9Q, 7D9R <br>
Course duration: 150 minutes <br>

## **Course overview**
Course ES72367 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR675 V3, machine types 7D9Q and 7D9R. <br>
The intent of this course is to provide an overview of the SR675 V3 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course Objectives** <br>
Students will be able to:
* Describe the Lenovo ThinkSystem SR675 V3 server and components
* List the SR675 V3 specifications
* Describe the SR675 V3 configurations and block diagrams
* Describe the SR675 V3 management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR675 V3

**Prerequisites**  
* [ES42430](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42430) – AMD EPYC processor architecture for ThinkSystem V3 servers  
* [ES51757C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757B) – Introducing ThinkSystem tools 
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination  
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing Lenovo ThinkSystem storage controllers  
* [ES40610D](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES40610D) – Introducing the Features on Demand technology  

**Topics**  
* Topic 1 – Product overview 
* Topic 2 – SR675 V3 system components 
* Topic 3 – System configurations and diagrams 
* Topic 4 – Problem determination and troubleshooting 
* Topic 5 – Hardware replacement tips 
* Topic 6 – End-of-course summary
