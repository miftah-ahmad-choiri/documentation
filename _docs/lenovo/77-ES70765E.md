## **Course overview**

Course ES70765E provides technical information to service personnel who are required to service and maintain the x3550 M4 Type 7914, x3650 M4 Type 7915/6188, x3650 HD and x3650 BD Type 5460. The intent of this course is to provide an overview and the in-depth architecture information on the systems.
The comparison between the current and the predecessor products allow you to understand the changes and enhancements. The problem determination section helps you understand how to perform service actions when encountering problems with the x3550 M4 Type 7914, x3650 M4 Type 7915/6188, x3650 HD and x3650 BD Type 5460.

**Course objectives**

- Provide an overview of the x3550 M4 Type 7914, x3650 M4 Type 7915/6188, x3650 HD and x3650 BD Type 5460.
- Describe the systems’ mechanical and cosmetic views.
- Describe the different subsystems.
- Explain how to perform problem determination activities and troubleshoot the x3550 M4 Type 7914, x3650 M4 Type 7915/6188, x3650 HD and x3650 BD Type 5460.

**Topics**  
- Topic 1 – Introducing the x3550 M4 Type 7914, x3650 M4 Type 7915/6188, x3650 HD and x3650 BD Type 5460 
- Topic 2 – Problem determination and troubleshooting 
- Topic 3 – End of course summary
