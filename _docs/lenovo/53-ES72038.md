## **Course overview**

Course ES72038 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR630 V2 machine types 7Z70, 7Z71, and 7D3Y.

The intent of this course is to provide an overview of the SR630 V2 specifications, components, system configuration, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course objectives**
- Describe the Lenovo ThinkSystem SR630 V2 server and components
- List the SR630 V2 server specifications
- Describe the SR630 V2 server configurations and diagrams
- Describe the SR630 V2 server management tools
- Describe the problem determination steps and explain how to troubleshoot issues with the SR630 V2


**Topics** 
- Topic 1 – Introducing the ThinkSystem SR630 V2 server 
- Topic 2 – SR630 V2 specifications 
- Topic 3 – SR630 V2 server configurations and diagrams 
- Topic 4 – Management tools 
- Topic 5 – Problem determination and troubleshooting 
- Topic 6 – End-of-course summary
