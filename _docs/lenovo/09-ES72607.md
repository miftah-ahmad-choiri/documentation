Machine type(s): 7DCL, 7DCM, 7DCN <br>
Course duration: 120 minutes <br>

## **Course overview**

Course ES72607 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR250 V3 (machine types: 7DCL, 7DCM, 7DCN).

The intent of this course is to provide an overview of the SR250 V3 specifications, components, system configurations, and management tools.

By watching the videos, you will learn how to install and remove system components.

**Course Objectives** <br>
Students will be able to:
* Describe the ThinkSystem SR250 V3 server and components
* List the SR250 V3 specifications
* Describe the SR250 V3 configurations and block diagrams
* Describe the SR250 V3 management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR250 V3

* [ES51757C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757C) – Introducing ThinkSystem tools 
* [ES52374](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES52374) – ThinkSystem tools for the ThinkSystem V3 platform  
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – Introducing ThinkSystem problem determination 
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing ThinkSystem storage controllers 
* [ES40610D](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES40610D) – Introducing the Features on Demand technology 
  
**Topics**

* Topic 2 – System components
