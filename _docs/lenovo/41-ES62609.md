Machine type(s): 7DCV <br>
Course duration: 72 minutes

## **Course overview**

Course ES62609 provides technical information for service personnel who are required to service and maintain the DM3010H storage system (machine type 7DCV).

The intent of this course is to provide an overview of the ThinkSystem DM3010H storage system specifications, components, system configurations, management tools, and the problem determination procedures.

By watching the videos, you will learn how to install and remove system components.

**Course objectives**

* Describe the ThinkSystem DM3010H and its components
* List the features and specifications
* Describe the cable connection for the DM3010H
* Provide an update of the ONTAP software bundle
* Describe the problem determination steps and explain how to troubleshoot issues with the DM3010H
* Describe the FRU replacement procedures
* Describe the software and firmware upgrade procedures

**Prerequisites** 
* ES71914C - Servicing the Lenovo ThinkSystem DM Series storage systems 
* ES42026 - ONTAP 9.7 Administration 

**Topics** 
* Topic 1 – Introducing the ThinkSystem DM3010H storage system 
* Topic 2 – Features and specifications 
* Topic 3 – DM3010H cabling and configuration 
* Topic 4 – ONTAP software bundle update 
* Topic 5 – Problem determination and troubleshooting 
* Topic 6 – Hardware replacement tips 
* Topic 7 – DM Series firmware updates
