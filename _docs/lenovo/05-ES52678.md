## **Course overview**

Course ES52678 provides an overview of the software tools supported by ThinkSystem servers and the functions they can be used for.
The intent of this course is to enable service personnel who are required to service and maintain ThinkSystem servers to understand how to use available software tools to perform common servicing tasks.

**Course Objectives Students will be able to:** 
• Describe the new features of the software tools supported by ThinkSystem V4 servers 
• Describe the difference between the software tools used on ThinkSystem V3 and V4 servers 
• Describe the features introduced in the newer versions of existing software tools that support ThinkSystem servers 

**Prerequisites**  
* **ES52374** – ThinkSystem tools for the ThinkSystem V3 platform 

**Topics**  
* Topic 1 – Tools for the ThinkSystem V4 server platform – overview 
* Topic 2 – UEFI on ThinkSystem V4 servers  
* Topic 3 – LXCE on ThinkSystem V4 servers 
* Topic 4 – LXCA on ThinkSystem V4 servers 
* Topic 5 – XCC3 on ThinkSystem V4 servers 
* Topic 6 – LXPM5 on ThinkSystem V4 servers
