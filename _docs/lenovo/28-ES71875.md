## **Course overview**

Course ES71875 provides technical information for service personnel who are required to service and maintain the ThinkSystem ST50 server machine types 7Y48 and 7Y49. The intent of this course is to provide an overview of the product and information about the architecture of the system.
By viewing these videos, the service personnel will also be familiar with the replacement procedures of the ThinkSystem ST50 server.

**Course objectives**

* Describe the ThinkSystem ST50 server.
* Describe the server features and specifications.
* Identify the server configurations and diagrams.
* Describe the problem determination procedures for ST50.

**Prerequisites**  
* [ES51780B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780B) - Servicing the Lenovo ThinkSystem storage controllers   

**Topics**  
* Topic 1 – Introducing the Lenovo ThinkSystem ST50 server. 
* Topic 2 – Server features and specifications. 
* Topic 3 – System diagram. 
* Topic 4 – Problem determination and troubleshooting. 
* Topic 5 – End of course summary.
