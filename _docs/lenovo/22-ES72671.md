## **Course overview**

Course ES72671 provides technical information for service personnel who are required to service and maintain the ThinkSystem SR780a V3 (machine type: 7DJ5). <br>
The intent of this course is to provide an overview of the SR780a V3 specifications, components, system configurations, and management tools. By watching the videos, you will learn how to install and remove system components.

**Course Objectives** <br>
Students will be able to:
* Describe the Lenovo ThinkSystem SR780a V3 and its components
* List the SR780a V3 specifications
* Describe the SR780a V3 configurations
* Describe the SR780a V3 management tools
* Describe the problem determination steps and explain how to troubleshoot issues with the SR780a V3

**Prerequisites**  
* [EES42373B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES42373B) – Intel Xeon processor architecture for ThinkSystem V3 servers  
* [ES51757B](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51757B) – Introducing ThinkSystem tools  
* [ES52374](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES52374) – ThinkSystem tools for the ThinkSystem V3 platform  
* [ES41759C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES41759C) – ThinkSystem problem determination 
* [ES51780C](https://lenovoedu.lenovo.com/course/view.php?idnumber=ES51780C) – Servicing ThinkSystem storage controllers  

**Topics**  
* Topic 1 – Product overview 
* Topic 2 – SR780a V3 system components 
* Topic 3 – System configurations and diagrams 
* Topic 4 – Problem determination and troubleshooting 
* Topic 5 – Hardware replacement tips 
* Topic 6 – End-of-course summary
