## **Course overview**

Course ES42692 provides an architecture overview of the Intel Xeon 6 (Intel code name: Birch Stream) platform processors.

**Course objectives** <br>
Students will be able to:
* Describe the features of Intel Xeon 6 processors in ThinkSystem V4 servers
* Identify the differences between Intel Xeon 5 (Eagle Stream) and Intel Xeon 6 (Birch Stream) Scalable processors
* Describe the Intel Xeon 6 processor naming rules
* Describe the supported memory features on ThinkSystem V4 servers with Intel Xeon 6 processors

**Prerequisites**  
Although there are no specific prerequisites for this course, you should have some knowledge of high performance computing (HPC) systems, be familiar with the general administration of a network cluster, and have problem determination and troubleshooting skills. 

**Topics**  
* Topic 1 – Intel Xeon 6 processor overview 
* Topic 2 – Intel Xeon 6 processor specifications 
* Topic 3 – Intel Xeon 6 RAS features 
* Topic 4 – Intel Xeon 6 processor SKU stack 
* Topic 5 – Intel Xeon 6 supported memory features 
* Topic 6 – End-of-course summary
